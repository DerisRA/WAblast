# WAblast installation and usage

## Requirements

Windows 10 or 11 (64-bit), an internet connection, and Microsoft Edge or Google Chrome for the direct WhatsApp Web connection.

A standalone Windows build, when provided separately, bundles Python and Node.js. The GitHub source repository does not itself include that build. For source setup, follow the requirements and commands in the [README](README.md).

## Connect and send

1. Open **WhatsApp Web**, select **Connect / request QR**, and scan the code using Linked Devices on your phone. Alternatively, configure a WAHA server or a compatible gateway under **Custom API**.
2. Create or edit a template, and optionally attach a supported image.
3. Enter recipients or import a CSV file. Configure your opt-out list before sending.
4. Select a template and delay, confirm recipient consent, and start the batch. A batch accepts at most 50 recipients.
5. Use the pause and stop controls as needed. The results table reports the status of each recipient.

English is the default language. Select **Bahasa Indonesia** above Terms & Conditions and restart the app to apply the change.

The direct WhatsApp Web integration uses an unofficial community library and may be affected by service changes or account restrictions. Only contact recipients who have agreed to receive your messages.
